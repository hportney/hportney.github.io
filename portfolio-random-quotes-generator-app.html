Random Quote Generator

Click the button for a motivational or famous quote!

Features:

  • Dynamic Quote Display: I built a button that, when clicked, instantly pulls a fresh quote from an expanding collection. This allows users to discover a variety of quotes and keeps the experience engaging each time they interact with the app.
  • Expandable Array: The quotes are stored in a JavaScript array, making it easy to add more quotes over time. This flexibility ensures that the app can grow without needing significant changes to the underlying code.
  • Simple and Intuitive Interface: I made the button large to clearly prompt the user to interact with it, ensuring the app is easy to use and encourages engagement without any distractions.
  • Instant Feedback: When the button is clicked, the quote updates immediately — no page reloads, no lag. I achieved this using DOM manipulation to make the experience feel smooth and responsive.

Tech Stack:

  • JavaScript (ES6+)
  • HTML5
  • CSS3

Skills Demonstrated:

  • DOM manipulation (dynamically updating the quote on button click without reloading the page).
  • JavaScript fundamentals (working with arrays, randomization, and event handling).
  • CSS for styling (creating a minimal, clean, and user-friendly design).
  • Responsive design (making sure the app looks great and functions well on all screen sizes).
