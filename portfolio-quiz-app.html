Description:

The Quiz App lets users choose from categories like music, history, trivia, and math. It displays questions dynamically, provides real-time feedback, and tracks scores. The design is straightforward, ensuring that users can easily navigate the app. The tech stack includes JavaScript, JSON, HTML5, and CSS3, showcasing skills in DOM manipulation, JavaScript fundamentals, JSON handling, responsive design, and UI/UX design.

Features:

  • Custom Quiz Categories: Choose from a variety of topics, with easy addition of new categories.
  • Randomized Questions: Every quiz is unique, thanks to random question selection.
  • Instant Feedback: Receive immediate feedback after each answer to help users track their progress throughout the quiz.
  • Results Display: View your final score in a clean, straightforward scorecard.
  • Content Updates: Easily expand the quiz pool by editing a JSON file.

Tech Stack:

  • JavaScript (ES6+)
  • JSON
  • HTML5
  • CSS3

Skills Demonstrated:

  • DOM Manipulation: Dynamically updates content without reloading the page, improving user experience.
  • JavaScript Logic: Utilized arrays, randomization, and event handling to power quiz functionality.
  • JSON Handling: I use JavaScript to fetch and parse quiz data from JSON to display questions and answers dynamically.
  • Responsive Design & CSS3: Applied CSS3 to create an adaptive layout for a consistent, user-friendly experience across all devices.
  • UI/UX Design: Prioritized intuitive, user-friendly design for easy navigation and interaction.
